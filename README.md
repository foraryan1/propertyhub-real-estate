# PropertyHub — Elegant Green

Frontend-only internship project for **Real-Time Property Rental, Maintenance & Amenity Management Platform**.

## Stack
- React + Vite
- React Router
- Lucide React
- CSS3
- LocalStorage for demo persistence

## Included
- Responsive landing page
- Resident login/register
- Resident dashboard
- Property details
- Maintenance request creation and filtering
- Maintenance status workflow
- Amenity availability and booking
- Overlap/conflict prevention
- Booking management and cancellation
- Profile and notification preferences
- Manager demo dashboard
- Responsive mobile sidebar

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
```

The `dist` folder can be deployed to Vercel/Netlify.

## Demo
Use any email/password on the login page.  
Choose **Manager demo** to access the manager dashboard.

## Scope note
This implementation is intentionally **frontend-only**, matching the internship frontend-development scope. LocalStorage provides persistence during the browser session; no Node.js server, database, payments, AI maintenance prediction or IoT integrations are included.
