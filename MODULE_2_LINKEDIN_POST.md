## Module 2 — Backend Development

I’ve completed Module 2 of my PropertyHub internship project by connecting the React frontend to a Node.js and Express REST API.

The module includes resident registration and login, protected APIs, maintenance request management, amenity bookings with booking-conflict checks, profile updates, and a Community Blog where residents can publish posts. I also added manager-only maintenance status updates and password hashing on the server.

For this learning module, the API uses in-memory storage. Database persistence with MongoDB or Supabase is planned for Module 3.

Tech used: Node.js, Express.js, React, Vite, REST APIs.

GitHub: https://github.com/foraryan1/propertyhub-real-estate
