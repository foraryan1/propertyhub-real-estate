🚀 Completed Module 3: Database Integration for PropertyHub.

I implemented MongoDB integration for the PropertyHub backend using Mongoose. When configured with a MongoDB connection string, resident accounts, salted password hashes, expiring sessions and community blog posts persist across server restarts. I also added an individual detail page for every community blog post.

Tech stack: React, Node.js, Express.js, MongoDB and Mongoose.
